# Review output

State the concrete outcome first.

For each actionable finding:
- File and line
- Triggering input or state
- Consequence and supporting code or observed result
- Smallest useful correction, if known

Verification:
- Scope and base revision
- Checks actually executed, with results
- Checks not executed and why
- Untracked files, truncated metadata or integration gaps affecting confidence

Do not pad the report with speculative findings, generic best practices or invented measurements.
