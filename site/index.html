Good questions
What actually fixes my code?
Codex's AI follows the PatchProof skills and edits the project using Codex's tools and permissions. This uses your Codex access and its usage limits. The Python helper records checks; this website compares file fingerprints. Neither contains its own AI model.
Are my files sent to a server?
The website does not upload selected files. It hashes watched files in this browser and keeps the result in memory. Reloading clears them. Using the AI plugin is separate: relevant project data is processed according to your Codex account settings. Commands you choose to run may themselves access the network.
Does a green result mean my project is safe?
No. It means the recorded command exited zero and the watched bytes match. The check might miss a bug, and its scope may be incomplete. Receipts can also be edited and are not signed attestations.
Does it add a watermark?
PatchProof does not add watermarks or attribution comments to your project files. The dashboard and check reports carry PatchProof branding. The source package includes its MIT license.
Can I use it without Codex?
The Python helpers and this viewer work without an AI account. The bundled agent workflows have been developed for Codex; compatibility with other AI hosts must be tested separately.
