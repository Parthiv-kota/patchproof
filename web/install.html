Install

One minute, no account.

PatchProof is a folder of Python and static files. Clone or download it, run the demo, and you have seen the whole idea. No AI host, no API key, no build step.

Requires
Python 3.11+
Optional
Git (change inventory) · Node.js 24 (website tests) · Codex CLI (AI workflows)
Dependencies
none — standard library only
Network
never, from PatchProof itself
Fast path

Run the demo

Get the source

pipx install patchproof
# or from source:
git clone https://github.com/Parthiv-kota/patchproof.git
cd patchproof && pipx install .

Or use Code → Download ZIP and extract it. Keep the hidden .agents and .codex-plugin folders; on Windows, a normal local folder beats a synced OneDrive one.

Watch a real failure become stale

python scripts/demo.py

It creates an isolated calculator, fails a test on purpose, fixes it, records the pass, then edits the code again. Open the DEMO=… path it prints.

Open the viewer

python -m http.server 8790 --bind 127.0.0.1

Then visit 127.0.0.1:8790/site/ for the receipt viewer, or 127.0.0.1:8790/web/ for this site. Both are static; stop the server with Ctrl+C.

Your own project

Record your first check

Choose a command you already trust — the test command you would run by hand — and name the files it depends on.

# no flags: watch source, tests and manifests by default
pp verify -- pytest -q

# narrow it when you want to
pp verify --watch-dir tests --watch-glob 'src/**/*.py' -- pytest -q

# the original long form still works
python scripts/receipt.py run \
  --repo /path/to/project \
  --watch-dir tests \
  --watch-glob 'src/**/*.py' \
  --out receipt.json \
  -- python -B -m pytest -q

# later, or before you hand the change over
python scripts/receipt.py status --repo /path/to/project --receipt receipt.json --html report.html

On Windows, quote the project path: --repo 'C:\Projects\my-app'. Output paths are relative to your current folder; the check itself runs inside --repo.

Optional

Install the commands globally

An editable install gives you patchproof and patchproof-snapshot, so nothing depends on where the source folder sits.

pipx install .        # isolated, recommended
# or: python -m pip install -e .

patchproof run --repo . --watch-dir tests --out receipt.json -- python -B -m pytest -q
patchproof status --repo . --receipt receipt.json
patchproof-snapshot --repo . --scope working
Optional

Add the Codex plugin

Tested with Codex CLI 0.160.0 on Windows. Sign in to Codex normally first; your account's usage limits apply.

# from the PatchProof folder
codex plugin marketplace add .
codex plugin add patchproof@patchproof-local
codex plugin list --marketplace patchproof-local --json

Start a fresh Codex session inside the project you want to review, then ask:

Use PatchProof to review my changes, explain any bugs in plain English, and record the checks you run. Ask before publishing anything.

Desktop picker activation and other AI hosts are unverified. If installing from a synced OneDrive folder fails to copy plugin files, extract the archive to a regular local folder and register that one.

Uninstall

It leaves nothing behind.

codex plugin marketplace remove patchproof-local   # if you installed the plugin
pip uninstall patchproof                           # if you installed the commands
rm -rf /path/to/patchproof                         # the source folder

Receipts and reports you generated are ordinary files wherever you chose to write them — delete those yourself. PatchProof writes nothing to your project and adds no attribution comments.

Something unclear?

Small reproductions and clearer explanations are the most useful kind of report.
