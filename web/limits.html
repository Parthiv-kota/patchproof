Limits and evidence

What this tool does not do.

PatchProof is deliberately narrow. The fastest way to judge it is to read what it refuses to claim — and then what has actually been run.

Scope

A receipt covers one command and one file list.

Coverage is explicit and incomplete

  • Unwatched files are invisible to the check.
  • Installed dependency contents are not tracked.
  • Environment variables and remote services are not recorded.
  • New files created during the run are not watched unless you listed them.
  • Directories, symbolic links, absolute paths and parent traversal are rejected outright.
  • 1–2,000 files, 64 MiB of watched content, 2 MiB of receipt JSON.

Sampling, not a snapshot

  • Hashing happens before and after the command, not atomically.
  • An edit made and reverted between samples can go undetected.
  • Timeout cleanup targets the launched process tree; detached children may escape.
  • Saved HTML reports describe the moment they were generated and never update themselves.
Trust

Receipts are local records, not attestations.

Editable and unsigned

Anyone with the file can change it. It does not authenticate the author or prove a command was honestly recorded by someone else.

Not a sandbox

The recorder runs your command with your normal permissions. It does not confine that process, install dependencies, or block network access.

Not a verdict

Exit zero plus matching bytes means the recorded command succeeded on those inputs. It says nothing about correctness, security or coverage.

Arguments and filenames are stored verbatim. They can be sensitive. Keep secrets out of command lines and review a receipt before sharing it.

Unverified

Where the evidence stops.

Platforms

Tested with Codex CLI 0.160.0 on Windows. Desktop picker activation, other AI hosts, and broad platform compatibility remain unverified. Installation from a synced OneDrive folder can fail to copy plugin files.

Comparisons

No benchmark advantage is claimed. There is no measured evidence of cost, token or speed savings, and no claim of marketplace approval or a production security audit.

Found something this page should say?

An honest limits page is only useful if it is complete. If a behaviour here is wrong or missing, that is a bug worth reporting.
